# Local tools

Start with the project README. `init_local_config.py` creates a private token without
printing it. `doctor.py` checks local setup. `local_routing_check.py --run` exercises
the configured local router/main model with synthetic input; `local_model_check.py`
checks typed tool contracts. `public_privacy_scan.py` reports publication risks without
printing secret values.

PDF/retrieval/RAG and accelerator tools remain available. `test_runner.py` selects
Full, Fast or Browser tests. Retired site diagnostics are inert text under `archive/`.
